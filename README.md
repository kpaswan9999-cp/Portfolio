# 🚀 Krishna Paswan — Portfolio

> Personal developer portfolio built with **React 19**, **TypeScript**, **Tailwind CSS 4**, and **Vite 8**.  
> Designed with the minimalist aesthetic inspired by [sanidhyy.name](https://www.sanidhyy.name/), featuring transparent ambient lighting, verified credential modals, dynamic project showcases, and instant resume downloads.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fkpaswan9999-cp%2FPortfolio)

---

## 🌟 Key Features

- ⚡ **Ultra-Fast Performance**: Built on Vite 8 & React 19 with zero runtime lag.
- 🎨 **Modern Minimalist Aesthetic**: Clean white default theme with subtle, transparent light purple ambient cloud glows on borders.
- 🏆 **Hackathons & Achievements Timeline**: Chronological vertical timeline showcasing national & international hackathon milestones (AI for Bharat Top 15 Finalist, Nebulon Hackathon, FAR AWAY Hackathon, Imarticus Data Science).
- 📜 **Interactive Certificate Viewer**: One-click modal lightbox with high-res previews, fullscreen inspection, and direct downloads for all verified certificates.
- 💼 **Production Project Showcase**: Featured interactive project cards for HireResumeAI, Raksha AI, TrashTrail, 5G Network Predictor, Climate Temperature Predictor, Flight Fare Analytics, and Supermarket BI.
- 📄 **Dynamic Resume Manager**: Download `Krishna_Paswan_Resume.pdf` with an on-the-fly URL settings modal allowing instant Google Drive link updates.
- 🌓 **Dark / Light Mode**: Seamless theme switcher with persistent user preference.
- 📱 **100% Mobile Responsive**: Fluid layouts with floating pill navigation.

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/kpaswan9999-cp/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** and select **`kpaswan9999-cp/Portfolio`**.
3. Keep default settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **"Deploy"**. Your portfolio will be live in seconds!
